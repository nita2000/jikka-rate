# 実家と空き家の試算表

実家の売却手残り・空き家の固定資産税・解体工事・相続手続き期限・墓じまいの公的相場＆損益分岐データベースサイト **『実家と空き家の試算表』** のモノレポです。

## 特徴・コンセプト

- **公的一次データ統合パイプライン (`pipeline/`)**
  - 総務省統計局「住宅・土地統計調査（47都道府県別空き家率・放置空き家率）」「小売物価統計調査（工事修繕・火葬料推移）」
  - 国土交通省「都道府県地価調査」「建築物除却（解体）単価基準」
  - 厚生労働省「衛生行政報告例（改葬＝墓じまい統計）」
  - 2023年12月施行「管理不全空き家・特定空き家の住宅用地特例解除（実効約4.2倍・本則最大6倍重課）」、2024年4月施行「相続登記義務化（10万円以下の過料）」「空き家3,000万円特別控除（買主解体要件拡充）」、2026年4月施行「住所変更登記義務化」に完全準拠。
- **3大インタラクティブ計算ツール（文字入力ゼロ・4項目選択式）**
  1. `/tools/disposal-simulator/`：実家を放置（税金＋管理費＋修繕）vs 解体して更地売却 vs 解体せずそのまま買取 5年・10年損益シミュレーター
  2. `/tools/akiya-tax/`：管理不全空き家・特定空き家の固定資産税「最大6倍重課（実効4.2倍）」＆相続登記ペナルティ計算機
  3. `/tools/hakajimai-simulator/`：遠方の墓を維持（管理料＋帰省費＋お布施）vs 墓じまい（撤去費＋永代供養/樹木葬）15年損益＆葬祭費シミュレーター
- **Programmatic SEO データベース**
  - `/pref/[pref]/`：全国47都道府県別の空き家率・実家土地相場・木造/鉄骨/RC解体坪単価・墓じまい相場ページ
  - `/cases/[slug]/`：主要40パターンの「実家・空き家・お墓タイプ別 維持費＆解体処分費・買取相場DB」
  - `/compare/[pair]/`：実家・終活の2択損益分岐比較ページ（全24組）
  - `/history/[year]/`、`/guide/`（データ検証ガイド5本）、`/llms.txt`、`/sitemap.xml`、`/rss.xml`

## セットアップ＆ビルド手順

```bash
# 1. Pythonパイプライン実行（生CSV生成 → 静的JSON生成 → 単体テスト）
python pipeline/fetch_jikka_stats.py
python pipeline/build_datasets.py
python -m unittest discover -s pipeline/tests -v

# 2. Astro 5 静的サイトビルド
cd site
npm install
npm run build
```

## GUIデータ更新アプリ（Windows）

`tools/じっかレート更新.cmd`（または `python tools/updater_app.py`）を起動すると、公的統計Excelまたはe-Stat更新データのドライラン検証・差分プレビュー・1クリックGitHub公開を実行できます。
